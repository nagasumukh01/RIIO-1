# Diffusion-Generated Face Dataset — Description

## Overview

This document describes the diffusion-generated face manipulation dataset created as
**Contribution 1** of the RobustDeep research gap implementation.

## Motivation

Existing benchmark deepfake datasets (FaceForensics++, Celeb-DF v2, DFDC) contain
*video-domain* manipulations produced by GAN-based or encoder-decoder-based face-swap
and reenactment methods. Modern diffusion-model-based generators (Stable Diffusion,
SDXL, FLUX, DALL-E 3) produce high-quality synthetic faces that:

1. Have different artifact distributions than GAN fakes.
2. Are not captured in any of the three main benchmark datasets.
3. Present a new challenge for detectors trained only on video-domain deepfakes.

## Dataset Structure

```
data/
  diffusion_face/
    raw/
      real/        ← genuine human face photographs
      fake/        ← diffusion-generated synthetic faces
    processed/
      real/        ← Haar-cascade cropped face regions, real
      fake/        ← Haar-cascade cropped face regions, diffusion fakes
    manifests/
      train_manifest.json
      val_manifest.json
      test_manifest.json
    metadata/
      diffusion_metadata_<timestamp>.csv   ← per-image provenance
    reports/
      diffusion_report_<timestamp>.json    ← build statistics
```

## Construction Protocol

### Step 1 — Source collection
- **Real images:** Portrait photos of real people. Must NOT include any face swaps
  or manipulated images. Sources: FFHQ, CelebA-HQ, or similar public face datasets.
- **Fake images:** Faces generated by diffusion models using text prompts such as
  "a realistic portrait of a person". Do NOT label GAN images, face swaps, or other
  non-diffusion fakes as diffusion-generated.

### Step 2 — Face detection
- Haar cascade (frontalface_alt2 → frontalface_default fallback).
- Minimum face size: 64 × 64 pixels.
- Images with no detectable face are recorded in metadata but excluded from splits.

### Step 3 — Near-duplicate removal
- Perceptual hash (pHash via `imagehash` library).
- Hamming distance threshold: 8 bits (configurable).
- Removes exact duplicates and near-identical renders of the same prompt.

### Step 4 — Splits
- 70% train / 15% val / 15% test.
- Deterministic (seed=42).
- Identity-safe by construction: diffusion images share no identity with real images.

### Step 5 — Metadata
- Per-image CSV: `source`, `label`, `face_found`, `saved_path`, `phash`, `generator`.
- Generator inferred from parent directory name (e.g., `sdxl/`, `fastsd/`).

## Pipeline Script

```bash
# Check what's missing:
python scripts/build_diffusion_dataset.py --dry-run

# Build with custom source directories:
python scripts/build_diffusion_dataset.py \
  --real-dir  data/diffusion_face/raw/real \
  --fake-dir  data/diffusion_face/raw/fake \
  --max-per-class 2000 \
  --phash-threshold 8
```
